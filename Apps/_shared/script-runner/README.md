# Script Runner shared files

This directory is the copied runtime catalog for the integrated Script Runner app.

- `data/scripts/` contains the discoverable `_script.yaml` entries and their source files.
- `data/shared/` contains helpers imported or sourced by those scripts.

Edit this copy when changing the sites5 integration. The source repository at
`/Users/arfan3/developer/gh/script-runner` remains independent.
